❓ Help & FAQ

This website is your own personal space for Music, Video, Gallery, Files and Notes — everything is stored on this device, and in the cloud too if you sign in.

How do I add something?
Open Music/Video/Gallery/Files, tap "+ Add", then either choose a file from your device or paste a direct link. You can also drag and drop files straight onto the Add box, and select multiple files at once.

Save vs Favourite vs Archive vs Hide — what's the difference?
🔖 Save — bookmarks it for later, item stays where it is.
⭐ Favourite — marks it as a favourite, item stays where it is.
🗄 Archive — actually moves it out of its tab into Archive; use "Unarchive" to bring it back.
🙈 Hide — moves it into the password-protected Private Vault.

I deleted something by mistake!
Open Menu → Delete (Trash). Deleted items stay there so you can Restore them, until you empty the Trash.

A YouTube/Vimeo video won't play ("Error 153")
This happens only if you're opening this page as a local file on your computer, instead of a real hosted website address. YouTube blocks embedding from local files — host this site anywhere (even a free static host) and it'll work.

A link I pasted won't play / shows a broken icon
The link probably isn't a direct file link (some sites block direct access, or the link points to a webpage rather than the actual file). Try downloading the file first and uploading it directly instead.

Where is my data stored?
On this device, in the browser's own storage. If you sign in with a cloud account, it also syncs to the cloud so you can use the same content on another device.

What is the Private Vault?
A password-protected area for hidden items. It's encrypted with a code only you know — if you forget it, hidden items can't be recovered.

Can I share things with other people, or let someone else use my account?
Share currently sends a link/file through your device's own share sheet or clipboard — it doesn't create a public link others can open without you. True public sharing links, multi-person collaboration with permissions, two-factor login, and importing directly from services like Google Photos or Dropbox all need a real backend server to work safely — they aren't available yet in this version, and won't be added until cloud sign-in is fully set up.

Search filters
The search page has From/To date filters and a size range filter — the size filter only matches Files, since Music/Video/Gallery/Notes don't carry a stored file size.

📄 Privacy Policy

This is a personal website for a single account holder — not a public service, and content isn't shared with other users unless you explicitly use the Share option.

What's stored, and where
Your music, videos, photos, files and notes are stored in this browser's local storage on this device. If you sign in with a cloud account, the same content is also stored in your cloud account so it can sync across your devices.

Who can see it
Nobody but you, unless you sign in to a shared/public computer, or you explicitly use Share to send an item to someone.

Your control over your data
You can export a full backup (Settings → Export .json) or delete everything at any time (Settings → Reset). Deleted items go to Trash first and are only removed for good when you empty it.

Third parties
No data is sold or shared with advertisers. If you paste a YouTube/Vimeo link, that video is streamed directly from YouTube/Vimeo's own servers, subject to their own privacy terms.

Private Vault
Hidden items are encrypted with a code only you set — even someone with access to this device's storage can't read them without that code.

🗑️ Delete

Deleted items stay here until you clear or delete them.

🔐 Hidden Vault

Hidden items are protected by your private code. The code is not stored in plain text.
